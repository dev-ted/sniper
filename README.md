# Black Friday deals

A price board for Black Friday specials in South Africa. Deals keep the item name, the rand price, a short description, the shop link, and the shop's image URL.

Makro's public Black Friday page is the first collector. Other shops are listed and ready for later collectors.

The app is set up for the Convex deployment `cool-raven-632`. After `npx convex dev` logs in and pushes the functions, run `npx convex run collectors/makro:collect` to save the first deals.
